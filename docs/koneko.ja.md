# 子猫軍団 — 猫軍団ライト版

> 猫軍団の品質原則を、PROプランのトークン予算に収まるサイズで。

## 子猫軍団とは？

子猫軍団（koneko）は、Claude CodeのPROプラン以下のユーザー向けに設計された猫軍団の軽量版です。独立レビューと証跡付きゲートという中核的な品質メリットを、トークン消費の激しいマルチエージェント階層なしで提供します。

## 含まれるもの

| 機能 | 含まれる | 備考 |
|------|---------|------|
| 独立レビュアー | あり | `koneko-neko` — タスクごとに1回のAgent呼び出し |
| 完了ゲート | あり | 3項目（簡易版） |
| 安全Tier | あり | Tier 1禁止、Tier 2要確認 |
| ファイル削除安全 | あり | `_deleted/` バッファ |
| 実装者≠レビュアー | あり | 核心原則を維持 |
| マルチエージェント階層 | なし | 親方/仕事/現場なし |
| 並列実行 | なし | TeamCreateなし |
| ホワイトボード/ダッシュボード | なし | 単一エージェントワークフロー |
| モジュール（しつけ） | なし | オプションモジュール非対応 |

## インストール

```bash
bash neko-gundan/scripts/install.sh koneko ./your-project
```

## 使い方

```
コードを書く
    ↓
子猫ゲート実行（証跡付き3項目チェック）
    ↓
koneko-nekoを起動してレビュー（Agent呼び出し1回）
    ↓
指摘があれば修正 → 完了
```

階層なし、儀式なし。ただ: **実装 → ゲート → レビュー → 完了。**

## トークン予算

| アクション | おおよそのコスト |
|-----------|---------------|
| 子猫ゲート（セルフチェック） | ~0（プロンプトルールのみ） |
| koneko-nekoレビュー | ~Agent呼び出し1回 |
| 安全ルール | ~0（プロンプトルールのみ） |
| **タスクあたり合計** | **~Agent呼び出し1回** |

比較: 猫軍団フル版（中隊）= タスクあたり3-5回のAgent呼び出し。

## フル版猫軍団へのアップグレード

MAX 5+に移行したら、モードを追加してアップグレード:

```bash
# ステップ1: フルレビュー機能を追加
bash install.sh quality ./your-project

# ステップ2: 並列実行を追加
bash install.sh implement ./your-project

# ステップ3: 戦略立案を追加
bash install.sh plan ./your-project
```

子猫軍団のファイルは競合しません。フル版に自然に置き換わります。

## 制限事項

- **並列エージェントなし**: 全作業は逐次実行
- **レビュー1回**: koneko-nekoはフィードバックを1回のみ。往復ループなし
- **3観点ルブリック**: 保守性とPurpose整合性チェックは省略
- **モジュール非対応**: しつけシステムは使用不可

これらはトークン効率のための意図的なトレードオフです。必要になったらフル版猫軍団にアップグレードしてください。
