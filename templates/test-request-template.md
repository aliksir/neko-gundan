# テスト依頼テンプレート（test フェーズ用）

> このテンプレートは `/neko-gundan test` の入力として使うテスト依頼のガイドです。
> フォーマットの完全一致は不要。口頭指示でも動けます。

## 必須項目（これがないとテストを始められない）

### 1. テスト対象
プロジェクト名と対象範囲。
- 例: 「my-app 全体」「my-app の認証機能だけ」「直近のコミットで変更されたファイル」

### 2. テスト種別
実施するテストの種類。指定がなければ自動判定。
- **単体テスト**: 関数・メソッド単位
- **結合テスト**: API・DB連携
- **E2Eテスト**: ブラウザ操作
- **セキュリティ**: semgrep, trivy, gitleaks 等
- **lint/型チェック**: tsc, ruff, eslint 等
- **全部**: 上記すべて

## あると助かる項目

### 成功基準
- 例: 「テスト全件通過」「カバレッジ80%以上」「セキュリティスキャンでHigh以上ゼロ」

### 既存テストの有無
テストが既にあるか、新規作成が必要か。

### 重点確認ポイント
「ここが壊れやすい」「ここのエッジケースが心配」等。

---

## 記入例（最低限）

```markdown
# テスト依頼

## 対象
my-app の認証機能（src/auth/）

## 種別
単体テスト + セキュリティ
```

## 口頭指示の例（これでも動ける）

```
/neko-gundan test "my-appの認証機能、セキュリティスキャン込みで"
```
