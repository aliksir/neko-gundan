# Auto Mode — Claude Codeの自動権限モードとの併用ガイド

> Claude Code v2.1.71以降、`auto` 権限モードが利用可能。Claudeが権限リクエストを自分で判断し、毎回の手動承認が不要になる。

## なぜ重要か

auto modeなしだと、Claude Codeはファイル編集・Bashコマンド・ツール呼び出しのたびに人間の承認を求める。猫軍団のようなマルチエージェント構成では、この承認プロンプトがエージェントごとに発生し、作業が頻繁に中断される。

auto modeはルーチンの権限判断を自動化する。猫軍団の安全プロトコルはその上で品質と正確性を担保する。

## 設定方法

### auto modeを有効化（推奨）

`~/.claude/settings.json` に追加:

```json
{
  "permissionMode": "auto"
}
```

または起動時に: `claude --permission-mode auto`

### 既存の許可リストはそのまま

`permissions.allow` のルールが既にあるなら**消さなくていい**。フォールバックとして機能する。auto modeはAI判断を「代わりに」ではなく「上に」追加する。

## Auto Mode + 猫軍団の二層構造

```
┌─────────────────────────────────────────┐
│         第1層: Auto Mode                │
│  「この操作を実行して安全か？」          │
│  （ファイル書き込み、Bash、ツール）      │
├─────────────────────────────────────────┤
│         第2層: 猫軍団                   │
│  「この作業は正しいと証明されたか？」    │
│  （レビュー分離、証跡ゲート、           │
│   異議申立、競合防止）                  │
└─────────────────────────────────────────┘
```

解決する問題が**違う**:

| 懸念 | Auto Mode | 猫軍団 |
|------|-----------|--------|
| 「このファイルを編集していいか？」 | ○ 権限判断 | — |
| 「この編集は正しいか？」 | — | ○ レビュー＋証跡ゲート |
| 「このコマンドは安全か？」 | ○ リスク評価 | ○ 安全Tier（Tier 1/2） |
| 「誰かがレビューしたか？」 | — | ○ 実装者≠レビュアー |
| 「エージェントは異議を申し立てられるか？」 | — | ○ OBJECTIONプロトコル |
| 「削除データは復元可能か？」 | — | ○ `_deleted/` バッファ |

**auto modeは手動の権限承認を置き換える。猫軍団は手動の品質保証を置き換える。**

## Auto Modeが置き換えないもの

auto modeは「権限判断」（このファイルを触っていいか、このコマンドを実行していいか）を扱う。以下は提供**しない**:

- 独立コードレビュー（猫軍団の玄人猫）
- 証跡ベースの完了検証（完了ゲート）
- エージェント間の競合防止（RACE-001）
- 不適切な指示への異議申立プロトコル
- 構造化された失敗分析（Reflexion）

これらは引き続き猫軍団の仕事。

## 安全性: 二重防御

両方を有効にすると、多層防御が得られる:

1. **Auto mode** が明らかに危険な操作をブロック（rm -rf、force push）
2. **猫軍団の安全Tier** が二重チェック:
   - Tier 1（絶対禁止）: auto modeが許可しても猫軍団がブロック
   - Tier 2（要確認）: auto modeでも人間にエスカレーション
3. **FIDES信頼レベル** が外部データをLOWタグ付け — auto modeは信頼レベルを知らないが、猫軍団は知っている

## 推奨設定

| シナリオ | 権限モード | 理由 |
|---------|-----------|------|
| 猫軍団でソロ開発 | `auto` | 中断を減らし、安全Tierにリスク管理を任せる |
| マルチエージェント（中隊以上） | `auto` | 必須 — エージェントごとの承認プロンプトで並列作業が非現実的 |
| 高セキュリティ・本番環境 | `default` + 許可リスト | 最大限の人間監視、中断は受け入れる |
| 軽い実験 | `auto` | 速さ重視。猫軍団のライトモード + auto modeが最速の安全オプション |

## 無効化

auto modeに問題がある場合:

```json
{
  "permissionMode": "default"
}
```

または `"disableAutoMode": true` でエージェントの利用を防止。
